# Loan Approval Prediction System

A Machine Learning based web application that predicts whether a loan application will be approved or not.

## Model

**Final Model:** XGBoost Classifier  
**Test Accuracy:** 95.79%

## Features

The system uses the following features:

1. **Applicant Income**
2. **Coapplicant Income**
3. **Marital Status**
4. **Dependents**
5. **Credit Score**
6. **Existing Loans**
7. **Age**
8. **DTI Ratio**
9. **Savings**
10. **Collateral Value**
11. **Loan Amount**
12. **Loan Term**
13. **Loan Purpose**
14. **Property Area**
15. **Education Level**
16. **Gender**
17. **Employment Status**
18. **Employer Category**

## Technologies Used

**Python | Pandas | Scikit-learn | XGBoost | Joblib | Streamlit**

## Project Description

The project includes data preprocessing, feature selection, train-test split, model training, model evaluation, cross-validation and deployment.

The trained XGBoost model is saved using Joblib and integrated into a Streamlit web application for real-time loan approval prediction.
